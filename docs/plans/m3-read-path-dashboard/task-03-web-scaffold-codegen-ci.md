# task-03 — `web/` scaffold: pnpm workspace, Next 16, Tailwind tokens, Vitest, ESLint/Prettier, codegen from `api/openapi.json`, CI web job

## Goal

A `web/` app exists that every later frontend task builds on: Next 16 (App Router, `output:
"standalone"`, tracing root at the repo root for the pnpm workspace), TypeScript strict +
`noUncheckedIndexedAccess`, Tailwind v4 with the design tokens defined once in
`src/app/globals.css`, Vitest 4 + React Testing Library, ESLint 9 flat config + Prettier, the
eleven FRONTEND-CONVENTIONS §1 scripts (every one a gate), `openapi-typescript` codegen over the
task-02 baseline committed under `src/types/generated/`, a server-side typed fetcher
(`src/lib/api/server.ts`) that reads `API_URL` and throws `ApiError` with the §8 envelope, a
`/healthz` route for the container healthcheck, `/` redirecting to `/alerts`, and a CI `web` job
that re-runs codegen and fails on drift. Every dependency is pinned to an exact version.
